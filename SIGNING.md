## Français

La version 1.21 conserve l’identifiant et la signature de la 1.20 : elle s’installe directement comme mise à jour, avec les données existantes.

La version 1.20 utilise un nouvel identifiant Android, indépendant de celui des versions antérieures. La clé de signature dédiée No Ads Studio est conservée.

Android considère cette application comme distincte : elle s’installe à côté d’une version antérieure à 1.20, sans la remplacer. Les prises privées, les réglages et les profils personnels ne sont pas transférés automatiquement. Gardez l’ancienne application jusqu’à avoir exporté et vérifié vos prises et noté vos réglages. La désinstallation de l’ancienne application n’est pas nécessaire pour installer celle-ci.

Les copies publiques exportées dans Music/Spectrum Audio et Pictures/Spectrum Audio peuvent être ouvertes manuellement. Ces dossiers d’export communs ne constituent pas un transfert automatique des données privées.

Les futures versions utilisant ce nouvel identifiant et cette signature pourront mettre à jour la version 1.20. Les sources publiques ne contiennent ni la clé privée officielle ni son mot de passe. Utilisez les empreintes SHA256SUMS.txt des publications pour vérifier les téléchargements.

## English

Version 1.21 retains the 1.20 application ID and signing key and installs as a normal update, keeping existing app data.

Version 1.20 uses a new Android application ID. It installs separately from earlier versions while retaining the dedicated No Ads Studio signing key. You can keep the previous app installed. Private recordings, settings and personal presets do not transfer automatically; export and verify recordings and note settings before removing any old installation. Public exports can be opened manually. Future updates using this new application ID and compatible signing identity can update 1.20 normally.

# Contributing / Contribuer

Bug reports, translations, tests and performance improvements are welcome. Start with an issue to discuss larger changes. Fork the repository, create a branch, make your changes and submit a pull request. Maintainers review proposals before merging them into the official project.

Preserve the GPLv3 notices, describe your changes and only submit work you have the right to contribute. Contributions to project-owned files are made under GPL-3.0-only; retain existing third-party notices. Do not commit audio recordings containing personal information, signing keys, passwords, tokens or local SDK configuration. Your own test build uses your own development signature.

Run the applicable checks documented in BUILDING.md. For a visual change, describe which device and Android version you tested and provide a screenshot without personal information if possible.

## Français

Les corrections, traductions, tests et améliorations sont bienvenus. Ouvrez un ticket pour discuter des changements importants, créez une copie du dépôt (fork), une branche, puis proposez une pull request. L’intégration dans la version officielle reste soumise à la revue des responsables.

Conservez les notices GPLv3 et celles des composants tiers. Ne proposez que du contenu que vous avez le droit de partager. Les contributions aux fichiers propres au projet sont sous GPL-3.0-only. N’envoyez aucune clé, mot de passe, configuration locale ni prise audio personnelle.
